# ECU Pro Tune

ECU Pro Tune é uma aplicação desktop para gestão visual de perfis de reprogramação automóvel, tuning de mapas, visualização de curvas, logs operacionais, backups, rollback, agendamento e modo de apresentação com efeitos sonoros.

## Stack
- Python 3.10+
- ttkbootstrap
- matplotlib
- playsound
- pydub
- Pillow

## Modos
- **Performance**: interface rápida e limpa para operação prática
- **Showcase**: interface com maior impacto visual e sons por evento
